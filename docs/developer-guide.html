Developer guide

Technical reference for integrating, building, and auditing V1. Not audited. Not on mainnet.

Invariant: Trading changes who owns a token. It never changes how much the vault owes. European, fully collateralized, one ERC-20 per series, Chainlink-only pinned to expiry.

Math — exact

PRICE_SCALE=1e18  BPS=10_000  OPTION_SCALE=10**18
UQ_SCALE=1e18*10**underlyingDecimals/10**quoteDecimals  // ≥1
C=10**underlyingDecimals
quoteRaw = underlyingRaw * price / UQ_SCALE
CALL cpo=C   PUT cpo=ceil(C*K/UQ)   requiredCollateral=ceil(a*cpo/SCALE)
CALL S≤K→0 else floor(C*(S-K)/S)   PUT S≥K→0 else floor(C*(K-S)/UQ)
writerRate=cpo-buyerRate   // by subtraction only
grossBuyer=floor(a*buyer/SCALE)  fee=floor(gross*exerciseBps/10000)

Oracle — settlement proof

Pinned: last round with updatedAt ≤ expiry proven by successor with updatedAt > expiry. Successor answer never used.
struct SettlementProof { uint80 chainlinkRoundId; uint80 chainlinkNextRoundId; }
require(roundId !=0) // ZeroRoundId
require(next != round) // RoundsNotDistinct
try getRoundData(round) // RoundUnavailable + id check
try getRoundData(next)  // SuccessorUnavailable
require(isImmediateSuccessor(feed,round,next)) // phase-aware: phase<<64|agg
require(updatedAtRound ≤ expiry)
require(updatedAtNext  > expiry)
require(expiry-updatedAtRound ≤ maxAge) // TooStale
require(answer >0) // OracleInvalid
price = answer * 10^(18-feedDecimals)

Premium & Guard

E_up=ceil(a*C/SCALE) E_down=floor(a*C/SCALE)
intrinsic = ceil(E_up*max(|R-K|,0)/UQ)
hardMax = floor(floor(E_down*(isCall?R:K)/UQ)*(BPS-exerciseFee)/BPS)
acceptableMin = ceil(intrinsic*(BPS-sellerTol)/BPS) // EMPTY_RANGE if min>max

Totals in quote raw — never per-option. Layer 1 (Kuru limit) is hard; Layer 2 (Guard) advisory until router reverts.

Deploy

  1. Deploy.s.sol — Deployer, Factory (bind + check), Guard; fees + PAUSER
  2. ConfigurePair.s.sol per pair — allowlist, pairConfig (heartbeat+buffer), cap
  3. Guard params if non-default
  4. HandOverAdmin.s.sol — multisig, renounce
  5. Kuru market → setKuruMarket write-once
  6. Trial cycle: mint → Kuru → settle → redeem/claim → sweep
