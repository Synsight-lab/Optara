# Optara brand kit

Logo, colours, type, icons, social images and backgrounds for the website, the app, X/Twitter, Discord, Telegram and
anything else that carries the Optara name. **Open [`guidelines.html`](guidelines.html)** (or `guidelines.png`) for the
full brand book.

Every asset is generated by [`source/build.mjs`](source/build.mjs); edit that, not the outputs.

## The mark

One coin cut by a call payoff:

| Part | Colour | Meaning |
|---|---|---|
| The coin, upper half | Monad Purple | Calls |
| The coin, lower half | Monad Berry | Puts. Both live in one coin because portfolio margin offsets them; the round counter nods to Monad's coin-like mark |
| The payoff line | Off-White → Breakout Mint | `max(S − K, 0)`: flat below the strike, then a ray that breaks out of the coin. Uncapped |
| The dot | Strike Ember | The strike, where the payoff turns and a trade happens; its spark borrows Kuru's bold energy |

The backgrounds draw real Black-76 option values: fans of call (purple → mint) and put (berry → ember) curves for
different times to expiry, hardening into the payoff and meeting at an ember strike.

## Colour

Monad's published brand palette is the foundation; Optara adds three colours with a job each.

| Name | Hex | Source | Use |
|---|---|---|---|
| Monad Blue | `#200052` | Monad | Primary ground |
| Monad Purple | `#836EF9` | Monad | Brand colour, calls |
| Monad Berry | `#A0055D` | Monad | Puts, depth |
| Off-White | `#FBFAF9` | Monad | Type on dark, light grounds |
| Breakout Mint | `#5CF2C4` | Optara | Calls, gains, the uncapped ray |
| Strike Ember | `#FF7A3D` | Optara (Kuru-inspired) | The strike, actions, alerts; a spark, never a fill |
| Lavender | `#C3B6FF` | Optara | Highlights, links on dark |
| Night | `#0D0024` | Optara | Deepest background |

Gradients: **Breakout** lavender → purple → mint (headline accents), **Strike** berry → ember, **Night** night → Monad
Blue. Proportion: ~70% night/blue, 20% purple/off-white, 10% mint, ember, berry. Tokens: [`tokens.css`](tokens.css)
(`--optara-*` custom properties) and [`tokens.json`](tokens.json).

Kuru publishes no colour values, so the ember is inspired by its "exploding star" identity rather than copied from it.

## Type

**Space Grotesk** Bold for the wordmark (lowercase "optara", tracking −2.5%) and headlines; Medium for taglines.
**Inter** (Monad's typeface) for body and UI. Both are OFL and ship in [`fonts/`](fonts/) with their licences.

### Website

```html
<link rel="icon" href="/favicon.svg" type="image/svg+xml">
<link rel="icon" href="/favicon-32.png" sizes="32x32" type="image/png">
<link rel="apple-touch-icon" href="/apple-touch-icon.png">
<meta name="theme-color" content="#200052">
<meta property="og:image" content="https://<domain>/og-image-1200x630.jpg">
<meta property="og:image:width" content="1200">
<meta property="og:image:height" content="630">
<meta name="twitter:card" content="summary_large_image">
<meta name="twitter:image" content="https://<domain>/og-image-1200x630.jpg">
```

Hero: `background: #0d0024 url(hero-1920x1080.jpg) center / cover;` with the mobile file under
`max-aspect-ratio: 3/4`. Headlines go top-left, where the art is quiet; for long copy add a left scrim
(`linear-gradient(90deg, rgb(13 0 36 / .88), transparent 72%)`, as `guidelines.html` does).

## Rules

- Clear space: at least the coin's radius on every side. Minimum size: 16 px (mark), 96 px wide (horizontal logo).
- Don't rotate the mark (the flat leg stays level), recolour it (never a red ray: red means loss), stretch it, or put
  the colour logo on mid-purple (use the white version).
- "optara" lowercase in the logo, "Optara" in running text.

## Regenerating

```bash
cd brand/source
npm install                                   # opentype.js, Space Grotesk, Playwright
node build.mjs                                # SVGs + tokens
CHROMIUM=/path/to/chrome node render.mjs      # PNG/JPEG + guidelines.png (omit CHROMIUM to use Playwright's browser)
```
